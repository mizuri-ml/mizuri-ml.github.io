LABORATORIO PRÁCTICO

Herramientas gratuitas.

Utilidades educativas que se ejecutan en tu navegador. No requieren cuentas ni envían los datos introducidos a nuestro servidor.

Procesamiento local · Sin base de datos · Sin instalación
HERRAMIENTA 01 / REDES

Calculadora de subredes IPv4

Calcula red, máscara, broadcast y direcciones disponibles a partir de una IPv4 y un prefijo CIDR.

Ideal para practicar direccionamiento y segmentación. /31 se interpreta como enlace punto a punto y /32 como dirección individual.

HERRAMIENTA 02 / SEGURIDAD

Generador de contraseñas

Crea contraseñas aleatorias utilizando la API criptográfica de tu navegador, sin enviar ni almacenar resultados.

Usa contraseñas únicas, un gestor de contraseñas y MFA cuando esté disponible.

Generada localmente mediante Web Crypto.

HERRAMIENTA 03 / INTEGRIDAD

Generador de hash SHA-256

Calcula el resumen SHA-256 de un texto y visualiza el valor hexadecimal obtenido.

Una función hash no es cifrado reversible. No sirve para almacenar contraseñas directamente: para eso se emplean esquemas específicos como Argon2id.

El cálculo se realizó localmente.
