CALCULADORAS ORIGINALES

Utilidades integradas

REDES IP

Calculadora de subredes IPv4

Calcula red, máscara, broadcast y direcciones disponibles a partir de una IPv4 y un prefijo CIDR.

Para /31 se admiten enlaces punto a punto y /32 representa una dirección individual.

SEGURIDAD

Generador de contraseñas

Genera contraseñas de forma local utilizando la API criptográfica del navegador. No se almacenan en el sitio.

Usa un gestor de contraseñas y activa la autenticación multifactor.

CRIPTOGRAFÍA

Generador de hash SHA-256

Calcula el hash SHA-256 de un texto en el navegador y muestra su representación hexadecimal.

Un hash no es cifrado reversible. No lo utilices como mecanismo directo de almacenamiento de contraseñas.
